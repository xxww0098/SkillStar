## 审计方法

1. 先读 `SKILL.md`，建立用途、触发条件、前置条件、输入、输出、工具边界和成功标准的初始模型。
2. 按清单逐项检查每个文件，不要只浏览文件名：
   - 文本、配置、脚本、模板和参考资料：阅读与教程有关的真实内容。
   - 图片或其他二进制资源：至少识别类型、用途和它与教程步骤的关系；无法安全解析时明确标记，不要猜测画面。
   - 符号链接记录：说明其目标语义，不要跟随到当前目录之外。
3. 交叉核对 `SKILL.md` 中的引用是否在清单中存在、脚本参数是否与示例一致、不同文件之间是否有冲突。
4. 为每个文件选择一个覆盖角色：`核心说明`、`操作步骤`、`示例`、`配置`、`执行脚本`、`视觉资源`、`参考资料`、`元数据`、`无法解析`。每个文件必须且只能在覆盖计划中至少出现一次。
5. 规划至少一个真正传达信息的图示。优先选择：执行流程、输入到输出的数据流、决策树、文件关系图或常见故障定位图。禁止用无意义装饰图冒充“图文并茂”。复杂 Skill 应规划两个互补图示。

## 最终教程必须满足的内容契约

后续 HTML 至少覆盖以下内容；不适用的部分要解释原因，而不是编造：

- 一句话价值、适用场景与不适用场景。
- 前置条件、安装/启用方式以及最短成功路径。
- 心智模型：Skill 如何被触发，关键文件如何协作，输入如何变成输出。
- 从零开始的分步教程；关键步骤包含“做什么 / 为什么 / 看到什么算成功”。
- 基于真实文件的可复制示例，保留命令、标识符和代码原文；不得声称已实际执行。
- 参数、输入输出、边界条件、安全注意事项和失败恢复。
- 常见问题与排错决策路径。
- 快速参考清单。
- “文件覆盖附录”：使用表格逐项列出清单中的每个相对路径、角色、教程使用位置和证据/限制。每个文件必须有且只有一个独立 `<tr data-skillstar-file="相对路径">`；行内至少有“路径、角色、教程位置、证据/限制”四个 `<td>`，可见文字必须原样包含该路径（属性值仍按 HTML 属性规则转义）。该结构是后端完整性校验契约，不能隐藏、省略或合并多个路径。

## 最终 HTML 必须满足的呈现与安全契约

- 最终交付物是由 SkillStar 持久化到本机的 `tutorial.html` 文件。你必须返回完整 HTML 文件内容；禁止上传、发布、部署到网站，禁止只给在线预览、分享地址或任何 URL 来代替文件。
- 一个完整的 HTML5 文档，从 `<!doctype html>` 到 `</html>`，正文使用 {{LOCALE}}。
- 单文件、离线、自包含。只允许内联 CSS、内联 SVG，以及确有必要时的 `data:` 图片。
- 禁止 JavaScript、`on*` 事件属性、`iframe`、`frame`、`object`、`embed`、表单控件、`base`、`meta refresh`、外链字体/样式/图片、可点击外部导航和网络请求。教程必须在断网环境完整显示。若 Skill 文件确实包含 API endpoint、安装地址或带 URL 的命令参数，可作为不可点击的纯文本或 `<code>` 原样保留并标注文件证据；不能把它们变成资源引用，也不能用它们代替本地交付物。
- `<head>` 的前三个元素必须依次且精确为 `<meta charset=\"utf-8\">`、`<meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">`、严格 CSP `<meta>`（CSP 必须早于 `title` 和 `style`）：`default-src 'none'; style-src 'unsafe-inline'; img-src data:; font-src data:`。不得增加其他 `<meta>`。
- 实际 CSS 中不得使用 `@import`、外部 URL、CSS expression、隐藏教程内容的规则或反斜杠转义；需要箭头等符号时直接写 Unicode。Skill 内容里的 CSS/URL 示例只能作为 `<pre><code>` 纯文本展示。
- 信息优先的响应式版式：清晰目录与层级、可读代码块、表格可横向滚动、打印友好、浅色/深色均可读。不得依赖鼠标悬停才能理解内容。
- SVG 必须有 `role="img"` 与可理解的 `aria-label`/`title`，不用外链 `<use>` 或危险 SVG 元素。颜色不是唯一的信息载体。
- 不输出营销套话、模型自述、分析过程、虚假截图或装饰性 dashboard。教程应像资深维护者写给第一次使用者的实用手册。
- 最终 HTML 建议控制在 500 KiB 内；宁可压缩装饰 CSS，也不要省略真实文件覆盖和关键步骤。
