# 28 — 次要字段

## 契约

Agent 行上的次要字段只显示环回 URL，例如 `127.0.0.1:21847`。不显示厂商主机，不显示密钥。

## 缝

字段由 gateway 的「当前写入 URL」投影而来，前端不拼接厂商端点。

## 人可以运行

保存 Codex 或 OpenCode 之后，该行的次要字段与文件里的 URL 一致，且是环回。

## 视觉

变量只有一个：次要字段的字符串。

裁剪：Agent 名称下方的那一行。

本档不评：行高、图标、选择器是否打开、三栏标题。

screenshot-critique，以及有 `assets/magpie/28-secondary.png` 时的 compare-screenshots。裁剪只盖住这行字。视口两档。preview-shots 约 5 分钟。

验收句：次要字段是环回地址；同一裁剪里没有厂商 URL，也没有密钥。

## 验证

- 投影测试：厂商端点即使存在于 v4 store，次要字段仍是环回
- 界面文本搜索测试用的厂商主机，结果为 0

## 可改

端口与路径之间的呈现，只要主机是 `127.0.0.1`。

## 不可改

不展示厂商 URL、不展示密钥、值来自实际写入。

## 必须保持绿

07 与 26 的测试。

## 会改这一档的反馈

次要字段出现 `api.openai.com` 或其它非环回主机。

## 决定

- 未保存过的 Agent 这一格为空，不预填厂商 URL。
