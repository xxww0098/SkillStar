# 收尾时的选择

对照 2026-09-30 已提交的代码重写。按档追加的过程稿在 git 历史里。这里只留规格没写死、最终代码仍这样的事。产品契约在 `docs/features/models/README.md` 和 `docs/architecture.md`。

信心低的排在前面。

## 先这样

- **空的分组可以保存。** 组里一个成员都没有时，写入成功，展开结果是空的。magpie 会拒绝这种组。信心：低。

- **一条正在听的请求不跑路由。** `serve` 把正文打到启动时给定的那一个上游根。协议翻译、effort 收束、视觉转述、脱敏在这条路上。路由排序、亲和、休息换上游、分类器、订阅签名，以及「首内容字节之前可以换上游」的保持写者，都有函数和测试，`forward_body` 不调用它们。页面把路由和亲和写进 `model_gateway.json`，这次转发不读。签名要调用方拿着账户自己调 `sign_upstream`。各档把它们留在库里，是为了不改已经钉住的假上游字节；没有后一档把它们接进监听。信心：中。

- **Claude Desktop 的 `/v1/models` 不过 `desktop_accepts`。** 这个函数只在写 Desktop 配置时使用。监听上的模型列表按可见名单过滤，不按 Desktop 的词表。信心：中。

- **smart 在同一档内部保持调用方给的顺序。** 已用份额不到 98 的在前，没有快照的在中，达到 98 的在后。档内不再按用量从低到高排，也不把 90 划成单独一档，也不按重置时间排。信心：中。

- **usage 只按注入快照里的已用份额从低到高排。** 份额相同就保持原来的顺序。没有快照的按已用 0，排在最前。不按最近发出的 token 做衰减。信心：中。

- **轮转遇上新回合时，顺序保持不动。** 函数只说明原因，不把下一名提到前面。信心：中。

- **没有会话头时，会话 id 是第一条用户消息的 FNV-1a，前缀是 `skillstar-`。** 内容相同、空白不同会命中同一条。时钟早于 stick 时，年龄算 0，不当作过期。信心：中。

- **用候选 id 对齐上次的回答者。** 同一账户上的不同模型和 effort 这一步分不开。信心：中。

- **OpenRouter 免费模型的共享池不单独换休息键。** 休息落在调用方点名的那一名候选上。连续失败次数也由调用方记，这个函数不保存。信心：中。

- **Retry-After 的日期只认 IMF-fixdate。** 星期几不核对。头按调用方给出的顺序，取第一条能解析的。其它失败如果带了已用满的窗口，休息到那个窗口恢复，不裁到 8 天，也不裁到 10 分钟。给 Agent 看的「去浏览器验证」这句话不在这里拼。信心：中。

- **Codex 的 TOML 只认基本双引号字符串和没有引号的一个词。** 单引号包住的值不解码。改一行赋值时，这一行末尾的注释消失，其它行按原字节留下。信心：中。

- **每一次 API 形态的保存都把 `skillstar-models.json` 写成空目录。** 可见名单不往这个文件里填模型行。已登录、并且 `model_provider` 已经是 `skillstar` 时，`model_catalog_json` 无论现在写着什么都当成我们放的键。信心：中。

- **没配置上游时，Codex 的非斜杠模型回 502，不连接 `api.openai.com`。** `count_tokens` 和 Gemini 的 `countTokens` 按正文原始字节数除以 4。Responses、图像和 Gemini 的生成请求原样转给那个上游根，路径保持来路。信心：中。

- **手写进文件的分组环，展开时从闭上的地方截断，不报错。** 写入仍然拒绝，文件不动。还不存在的 `group/<id>` 可以写进成员，展开时跳过。分组 id 按原文保存，不去掉大小写。展开时同一个成员只留第一次出现的位置。文件读不出来时，展开当成没有分组。信心：中。

- **规则点名的成员不在展开结果里时，不把它插进去。** 不套用一份已知 Agent 的别名表。effort 按规则上写下的原文比较。单条规则解析失败就跳过这一条。intent 去掉空白之后若是空的，就不算带 intent。bearer 没有点名时，Mozilla 且带 ` Claude/` 的 User-Agent 认成 `claude-desktop`。信心：中。

- **分类器这一步不自己打开 socket，问句由调用方发出。** 置信度低于 0.4 仍算模型答上来了。缓存按模型 id、意图列表和消息一起认，结论保留 24 小时。问句里带上调用方给的消息原文。不给自动 effort 打分。规则上的 intent 和回答比的时候忽略 ASCII 大小写。前面已经有一条不带 intent、而且当前请求能命中的规则时，不再问后面的 intent。信心：中。

- **脱敏的四个开关各自生效。** 占位符是 `{{种类_}}` 加 8 位小写 base32。自定义规则的字段是 `kind`、`prefix`、`regex`。不是 JSON 就当整段文字遮；不是 UTF-8 就原样返回。`model`、`id`、`role` 这类键下面的字符串，以及 `data:` 开头的字符串，不遮。密钥文件已有至少 32 字节就沿用前 32 字节。进程里的占位符超过 20 万条时丢掉一半。信心：中。

- **视觉转述不在目录里自动挑一个能看图的模型。** 只改写翻译之后的 Chat `image_url`。成功的描述才留下。库本身不睡满 2 分钟，调用方守这个时间。信心：中。

- **请求的 effort 不在目录顺序里时，有子集就用子集的第一项。** 子集里的名字一个都对不上目录时，当作没有子集，回到就近。等级名字不区分 ASCII 大小写，`provider/model` 这个键区分。给出的顺序是目录顺序。不往 Agent 文件里新造等级数组。信心：中。

- **找可见家族时，行的 `id` 区分大小写。** 名单项和别名不区分 ASCII 大小写，也不做子串。分组写成 `fast` 或 `group/fast` 都算同一个 id。信心：中。

- **距离相等的 effort 取更高的一级。** 请求模型是 `group/<id>` 时，用该组第一个已保存成员的固定值。未固定时，下拉显示一个圆点。信心：中。

- **显示名最多 80 个 Unicode 标量，并且拒绝 `://` 和 `sk-`。** 文案写在组件里。信心：中。

- **Provider、分组、配置档和局域网这些控件的短文案写在组件里。** 开发页的夹具分组叫 `fast`，成员是 `openai/gpt-test`；配置档夹具叫 `work` 和 `home`；开发页一开始是环回。页面查询各读一次，不推事件。信心：中。

- **已经在听的进程不因为改成局域网而重新绑定。** Codex 的 origin 仍由调用方传入。NAT 没探到地址时仍写 `127.0.0.1`。不记住已停止的发行版。`apply_gateway("codex@wsl:…")` 和 `apply_gateway("cindy")` 仍返回未托管。信心：中。

- **文件型写入是整份替换，不是逐键拼进用户原来的文件。** Claude Code 的 `settings.json`、Desktop 的四份文件、Hanako 的 catalog 和 agent 配置都这样。模型列表这一次只放传入的那个 `model_ref`，Hanako 活着时不刷新 stash。Alma 已经指向网关的 openai 或 custom provider，名字不是 `skillstar` 也拿来改；占位密钥是 `skillstar-alma`。Cindy 的展示名和 id 都是小写 `skillstar`。信心：中。

- **取消托管放回的是接管前的整份文件。** JSON 键序按写入模板固定。测试沙箱设着时，厂商的目录覆盖不生效。Windows 上不检查 stash 是不是 `0600`。信心：中。

- **侧栏不再单独做一套「最近供应商」。** Gateway 栏列出最近 60 条已转发的调用。读取还没成功时不画空态句子。没写进文件的 Agent，环回那一格为空。信心：中。

## 已定，按这个做

- **Goose、Cursor CLI、Copilot CLI、Devin 连模型名都不写。** `apply_gateway` 返回 `agent_not_managed`，目录里不出现新文件。不为 Devin 造 endpoint 字段。入站签名里的 `cursor`、`devin`、`github-copilot` 仍是账号头，不是这四个 id 的配置写入。信心：高。

- **空的 effort 子集和缺省一样，用目录里的全部等级，未固定的请求仍就近。** 有对得上的子集时，按目录顺序收进子集，不按数值距离。成员上的固定等级按整个目录收束，子集不改它。`xhigh` 收成 `max` 只发生在 Claude 进程的启动参数上。信心：高。

- **可见名单缺省或空数组时，看到全部模型。** 名单收窄 `/v1/models`、选择器和写进该 Agent 文件的目录。已经保存的 model ref 留在原字段。名单外的 id 仍可以请求。Codex 的目录文件仍是空的。`/v1/models` 的每一项只有 `id` 和 `object`。信心：高。

- **显示名不改出站 `model`。** 键是 `provider/model`。空名字、换行、超长、含 `://` 或 `sk-`、或目录里没有这个 id 时不写文件。信心：高。

- **写进 Agent 文件的地址总是 `http://127.0.0.1:<端口>`。** 局域网让进程听 `0.0.0.0` 和原来的端口，不改这句地址。端口 `3425` 拒绝绑定。信心：高。

- **网关是独立 crate，skillstar 依赖只有 `skillstar-core`。** models 与 usage 不依赖它，它也不依赖 models、usage、decision、app。只有 `skillstar-app` 依赖它。`src-tauri` 不直接依赖它。密钥表保持 v4，不加路由列。启动不改 Agent 文件。信心：高。

- **不把 Usage 的 access token 放进 Claude 子进程，也不代刷新。** 占位 bearer 是 `skillstar` 或 `skillstar-<id>`。不提供配额路径。最近 60 条调用只留在进程里。信心：高。

- **三栏同时摆开。** 读板失败时标题仍在，不把错误字符串画出来。Providers 一行是名称和掩码后的凭据摘要，没有明文密钥，没有厂商 URL。信心：高。

- **stash 里的空字符串表示这个键原来不存在。** 同一个键第一次放进 stash 的值留下，后来不再覆盖。取消托管留下 Codex 的提供商表和空目录文件。已登录不写提供商表。只改第一个表之前的根赋值。信心：高。

- **地址解析失败就是错误。** 空的环境变量用默认 `127.0.0.1:21847`。写错的地址不回退到默认。`skillstar gateway` 在打开 CLI 的迁移之前就返回；后面不是正好一个 `serve` 时，用法写到 stderr。信心：高。

- **请求正文和响应正文没有读超时。** 只有读头 30 秒，以及两次请求之间的空闲 5 分钟。等响应头的 10 分钟把建立连接的时间也算进去。流式客户端的连接池跟短探测共用一套数。一个连接上不等待的第二条请求，不按空闲重新计时。信心：高。

- **未知路径不列出配额。** 含 `/` 的未知模型是本机错误。Codex 的 WebSocket Upgrade 回 426。GET 路由同时应答 HEAD，正文为空。聊天正文不是合法 JSON 时，仍按原字节转发。信心：高。

- **空字符串和认不出的路由词都是 smart。** 认不出的亲和词都是 auto。少于两个候选时，轮转不推进计数。`model_gateway.json` 缺了或不是 JSON 时，路由是 smart，文件保持原样。信心：高。

- **429 上的余额词不算余额，除非正文里有 `insufficient_quota`。** 已用份额达到 98 才采用注入的窗口。满 1 小时整的 Retry-After 仍算 1 小时，再多 1 秒裁掉。验证的 hold 满 1 分钟整就不再用上一次的拒绝顶上。信心：高。

- **中止 Claude 子进程时单独成组，再杀整组。** 助手把工具调用用裸的 `TcpStream` 发到环回回调，不走代理客户端。回调先看对端是不是环回。`claude-mcp-helper` 比别的早期子命令更早返回，stdout 只有 MCP 帧。信心：高。

## 琐碎

- 空目录的字节是一格缩进、末尾没有换行：`{\n "models": []\n}`。夹具末尾多一个换行会在比较前丢掉。允许的品牌替换先换 `Magpie`，再换 `magpie`。
- 六个旧 sync 函数还在，函数体不写盘。网关不猜 Codex 登录态，调用方传入形态。
- Grok 的签名版本固定写成 `1.0.41`。同一个 catalog 有多张卡时用 active pin，对不上就用列表里的第一张。
- provider 块里只有这次传入的那一个模型。Claude Code 的 sync 仍会列出写不进去的角色，OMP 的 sync 不列。
